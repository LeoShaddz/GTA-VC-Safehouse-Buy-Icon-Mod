# GTA Vice City Safehouse Buy Icon Mod

This mod adds icons for purchasable safehouses to the minimap and map. It does not include icons for assets, as Silent Patch already handles that.

![Screenshot](https://i.imgur.com/wlLqV5S.jpeg)

# Installation

1. Install the Ultimate Asi Loader and Modloader in in the game's root folder
2. Extract the file "GTA.VC.Safehouse.Buy.Icon.Mod.v1.0.zip"
3. Copy the "Safehouse Buy Icon" folder into the "modloader" folder, which is located in your game's root directory.
4. Done
